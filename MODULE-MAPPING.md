# Six-module syllabus mapping
1. **HTML/CSS:** semantic page layout, forms, lists, CSS selectors, box model, responsive layout, navigation.
2. **JavaScript/JSON:** event handlers, client validation, JSON request/response payloads, state-driven UI updates.
3. **jQuery:** `client/public/jquery-demo.html` demonstrates selectors, `.val()`, `.text()`, `.css()`, click events, `.find()` and `.fadeToggle()`. Kept separate from React DOM.
4. **React:** JSX components, props, events, conditionals, lists, forms, `useState`, `useEffect`, responsive styling.
5. **MongoDB:** `users`, `jobs`, `applications` collections; Mongoose schemas, CRUD, regex search and selected fields.
6. **Node/Express:** async routes, REST APIs, middleware, JWT auth, role checks, Mongoose, Multer file uploads and error handling.
